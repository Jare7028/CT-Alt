# Requests desktop component review

Run `node scripts/test-requests-ui-browser.mjs` from the CT Alt checkout. The guarded runner requires unused loopback port 5197, refuses to overwrite its temporary fixture route, disables Supabase configuration, and removes its own server/route/dev type cache on completion or signals. Requests API traffic is intercepted by the browser tests using synthetic records; this suite does not establish signed RLS or database acceptance.

The 30 cases cover the three-column desktop geometry at 1444×960, creation/editing and captured assignee identity, actual pointer drag/drop and keyboard movement, exact counts/search/cursor paging, duplicate-page rejection, role-safe controls, current access denial, imperative pending-write guards, exact UUID/payload retry, field-free reconciliation and fresh-read recovery, malformed acknowledgement binding, revision conflicts, changed company/actor scopes, and decoded acknowledgements after departure. Delayed editable and read-only detail tests verify focus entry, Tab containment, and Escape return focus. A focused Title submitted into a held POST retains dialog focus even when all controls are disabled; picker loading also preserves focus containment. The malformed initial data and recovery marker cases remain locked.

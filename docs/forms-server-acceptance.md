## Signed API contract

GET `/api/forms` returns the raw catalog DTO; GET `/api/forms/[id]` returns a scoped manage or mine detail. GET `/api/forms/roster` provides a searched, bounded current Auth-user picker. GET `/api/forms/[id]/responses` exposes submitted management summaries only. GET `/api/forms/[id]/responses/[responseId]` returns the shared frozen schema once and at most ten prior answer versions. POST `/api/forms` returns `{saved}` for explicit revisioned commands. POST `/api/forms/reconcile` returns the raw field-free recovery DTO after two fresh resource-authorized signed RPC reads. Every response is private/no-store; mutations enforce same origin, strict property/duplicate detection and raw/semantic UTF8 budgets.

Owner/admin management does not imply respondent assignment. Managers/employees and assigned administrators can access only their own original Auth-user response on a currently assigned published form. Agent-record relinking transfers no Forms identity. Management reads, direct table RLS and granted private helpers deny other actors' progress IDs/answers; progress overwrite creates no immutable answer history. Publication freezes the schema. Archives retain submitted management history and prohibit response/review mutations.

UUID receipts bind actor/company/action/canonical payload hash, not immutable copies of progress answers. Reconciliation waits the same actor/UUID mutex with a fresh VOLATILE snapshot and current authorization. An absent operation becomes a field-free durable tombstone: a delayed original HTTP/DB request cannot revive it. An explicitly initiated new UUID is required. A marker cannot recover discarded unsent answer bytes.
